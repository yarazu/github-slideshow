## 🎮 Neon-Mampfer 3D

Ein Labyrinth-Arcadespiel in 3D im Stil der klassischen Punktefresser: Friss alle Punkte, weiche den vier Geistern aus und dreh mit Kraftpillen den Spieß um.

- **Spielen:** `neon-mampfer/index.html` im Browser öffnen (oder über GitHub Pages unter `/neon-mampfer/`).
- **Steuerung:** Pfeiltasten oder WASD · `C` Kamera wechseln · `P` Pause · `M` Ton · am Handy wischen oder Steuerkreuz.
- **Kameras:** Arena (ganzes Labyrinth), Verfolger (dicht hinter dir), Schulterblick (lenken aus Sicht der Figur).
- **Geister mit eigener KI:** Funke jagt direkt, Rosa schneidet den Weg ab, Frost rechnet mit Funkes Position, Glut wird in deiner Nähe scheu. Wechsel zwischen Jagd- und Rückzugsphasen wie im Original-Arcade.
- **Extras:** Bonusfrüchte, Punkte-Kombos für Geister, Extraleben ab 10.000 Punkten, steigende Schwierigkeit pro Level, Rekord wird im Browser gespeichert.

Technik: eine einzelne HTML-Datei mit [three.js](https://threejs.org/) (r128, per CDN) inklusive Bloom-Leuchteffekt; Sound wird mit der Web Audio API live erzeugt.
